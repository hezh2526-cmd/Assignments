# 结果目录

当前未运行实验，因此这里不包含虚构数值。

执行 `code/run_all.ps1` 后，程序会自动创建：

- `tables/`：数据统计、全部重复实验记录、均值与标准差、最终指标、分类报告和逐样本预测；
- `figures/dataset/`：USPS 全类别样例、类别分布、Sonar 类别均值曲线和相关矩阵；
- `figures/sweeps/`：不同训练比例和不同 K 值下的 OA、错误率、AA、Kappa 曲线与热力图；
- `figures/reference/`：三种方法的指标对比、混淆矩阵、Fisher 投影和定性错误样例；
- `run_metadata.json`：运行配置、环境版本和耗时。
